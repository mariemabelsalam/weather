# 🌤 Weather App

A simple weather forecast application built with *HTML, CSS, and JavaScript*.  
The app fetches data from the [WeatherAPI](https://www.weatherapi.com/) and displays the forecast for *today, tomorrow, and the day after tomorrow*.

## 🚀 Features
- Get weather forecast based on *your current location* (using Geolocation).
- Search for any *city* to get its weather data.
- Displays:
  - City name
  - Temperature
  - Weather condition & icon
  - Humidity
  - Wind speed & direction
- Shows forecast for *3 days* (Today, Tomorrow, Day after Tomorrow).

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript (Fetch API + async/await)
- WeatherAPI
